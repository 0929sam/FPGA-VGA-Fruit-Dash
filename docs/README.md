# docs/ 使用說明

- `sprites/`：角色與道具的原始照片（apple / banana / bomb / clock / player），
  轉檔成 `rtl/*.mif` 點陣圖之前的來源素材，放在 README 裡當作「素材管線」的展示圖。
- `media/`：實機錄影與 demo 動圖。
  - `demo.gif`：README 最上方自動播放的 6 秒精華片段
  - `IMG_8431.mp4`：已壓縮的完整版（約 9MB）
  - `IMG_8434.mov`、`IMG_8435.mov`：原始錄影（39MB / 23MB），GitHub 網頁上點進去後
    要按 `View raw` 下載才能看，不會內嵌播放
  - `IMG_8438.HEIC`：iPhone 照片格式，大部分瀏覽器（含 GitHub 網頁預覽）都無法直接顯示，
    建議之後用 iPhone「共享」或 Windows「小畫家」另存成 `.jpg` 再換上
